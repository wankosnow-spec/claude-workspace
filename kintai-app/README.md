# 出張・欠勤連絡表アプリ

総務部が毎日手打ちしていた「出張者一覧表」と「欠勤者（連絡）」を作るアプリです。

- AIにおまかせ入力：電話やメモの内容をそのまま書くと、AIが表の形に直します
- 前の日から続く出張・休みは、終わりの日まで毎日自動で表に出ます
- 「印刷用ファイルを保存」で、今までと同じ形の表をA4で印刷できます
- 「文章でコピー」でメールやチャットに貼り付けられます

公開版（Claude上で使う版）: https://claude.ai/artifact/MefWeHQzgA7iczVvj1aCxG

`index.html` をパソコンでダブルクリックして開くこともできます（その場合はAI入力は使えず、データはそのパソコンの中だけに保存されます）。
