# 出張・欠勤連絡表アプリ（AI不使用）

総務部が毎日手打ちしていた「出張者一覧表」と「欠勤者（連絡）」を作るアプリです。
AIもインターネットも使いません。ファイル1つで動きます。

## 使い方
1. `出張欠勤連絡表.html` をパソコンに保存し、ダブルクリックで開く（Edge または Chrome）
2. 最初に「② 社員名簿」で名簿を登録する（最初は空です）
3. 毎日「① 今日の表を作る」で、所属→氏名を選び、行先や事由を入れる
4. 「印刷する」で、今までと同じ形のA4の表を印刷

- 前の日から続く出張・休みは、終わりの日まで毎日自動で表に出ます
- データはそのパソコンのブラウザに保存されます。「③ バックアップ」で定期的に保存してください

`index.html` は見本画面（claude.ai）用の同じ中身です。
